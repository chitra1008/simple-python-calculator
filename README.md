# Simple Calculator with Input Validation

## Description
This project is a simple command-line based calculator written in Python.  
It allows users to perform basic arithmetic operations with proper input validation and error handling.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Input validation for numeric values
- Error handling for division by zero
- User-friendly menu

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed on your system.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run the following command:

```bash
python calculator.py
